## What's new in v0.6.4

- **Smoother card screens.** The holographic foils on rare, epic and legendary cards used to repaint the whole card every frame and use expensive colour blending. They now slide a GPU layer instead and look the same. While a card screen (draft, resupply, crate, index) is open, everything behind it stops animating.
- **Supply caches give better loot.** They now hold a real tactic card with proper rarity odds: common 40%, uncommon 35%, rare 18%, epic 6%, legendary 1%. Before, they almost always fell back to a common card.
- **No more blueprint spoilers.** Planning a move through ruins or a cache no longer shows what's inside; you find out when your units actually get there.
- **The Blueprint box moved** to the bottom right, so the log and event chips on the left no longer cover it.

## ⬇ Download and play

1. Download **`Sector.exe`** below and double-click it. The **SECTOR server window** opens: a live dashboard with your invite addresses, players, game status and updates.
2. Press **O** to open the game in your browser, or go to **http://localhost:3000**. Everyone plays in the browser.
3. Friends on the same Wi-Fi open the **INVITE** address shown in the server window. Press **C** to copy it.
4. Already on v0.4 or later? The server window says **v0.6.4 is out — press U** and updates itself.

> **Windows says "Windows protected your PC"?** Click **More info → Run anyway**. SECTOR isn't code-signed yet, so SmartScreen doesn't recognise the publisher. Microsoft Defender scans it clean, and in-app updates (press **U**) don't trigger the warning again. The first launch also asks for network access: tick **Private networks** so friends can connect.
